# Mihomo Rulesets

Reproducible Mihomo MRS artifacts generated from canonical upstream text
rulesets. This repository currently publishes Sukkaw's reject domainset without
changing its rule coverage.

## Published artifact

Stable rolling-release URL:

```text
https://github.com/skyswordw/mihomo-rulesets/releases/download/rolling/reject_domainset.mrs
```

Mihomo provider example:

```yaml
rule-providers:
  reject_domainset:
    type: http
    behavior: domain
    format: mrs
    url: https://github.com/skyswordw/mihomo-rulesets/releases/download/rolling/reject_domainset.mrs
    path: ./rule_set/sukkaw_ruleset/reject_domainset.mrs
    interval: 43200
```

MRS is a Mihomo/Clash.Meta format. Original Dreamacro Clash, sing-box, and
Surge require their own rule formats.

## Automation

GitHub Actions checks the canonical source every six hours. An update is
published only after all of these checks pass:

- minimum source entry and byte counts;
- pinned Mihomo archive checksum;
- deterministic conversion from the same source;
- minimum artifact size;
- Mihomo configuration validation.

If any check fails, the existing rolling artifact remains unchanged. Metadata
and SHA-256 checksums are published beside the MRS file.

To regenerate locally:

```bash
MIHOMO_BIN=/path/to/mihomo ./scripts/update-rulesets.sh
```
